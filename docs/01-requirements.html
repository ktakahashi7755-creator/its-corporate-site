Section 01

文書概要

本書は、ITS合同会社のコーポレートサイトを「世界最高峰・プロフェッショナルレベル」に刷新・構築するにあたり、全要件を定義する文書である。ポケモン株式会社の公式コーポレートサイト（corporate.pokemon.co.jp）を世界水準の日本語コーポレートサイトの参照モデルとして採用し、そのデザインクオリティ・UX設計・アニメーション手法を本サイトに応用することを目的とする。

本書の読み方：本要件定義書は「基本設計書（02）」「詳細設計書（03）」と一体で運用される三層構造の設計ドキュメントシリーズ第一弾である。WHY（なぜ作るか）を定義する。

Section 02

背景と目的

2.1 プロジェクト背景

ITS合同会社は、システム受託開発・ITコンサルティング・Web制作・デザイン制作の4事業を展開するIT企業である。現在のコーポレートサイトは基本的な情報提供機能を有するが、以下の課題が存在する：

  • BtoBクライアントへの「信頼感」「技術力」「プロ意識」の訴求が不十分
  • アニメーション・インタラクションが他社競合サイトと比較して劣位
  • 採用・PR観点でのブランドイメージ形成が弱い
  • 自社プロダクト「Familink」の魅力が十分に伝わっていない

2.2 目的

  1. ブランド格上げ：訪問者が「この会社は信頼できる」と即座に感じるビジュアルクオリティを実現
  2. 商談獲得率向上：お問い合わせCTAへの導線を最適化し、コンバージョン率を改善
  3. 採用ブランディング：優秀なエンジニア・デザイナーが「ここで働きたい」と感じるサイト設計
  4. SEO強化：競合キーワードでの検索露出向上
  5. プロダクトPR：Familinkの魅力・差別化ポイントを視覚的・動的に伝える

5.3 アクセシビリティ要件

  • フォーカスリングの視認性確保

Section 09

制約条件

種別制約事項
技術制約Pure HTML / CSS / Vanilla JS のみ。React/Vue/TypeScript 等のフレームワーク・バンドラー不使用
ホスティング制約GitHub Pages (静的ファイルのみ。サーバーサイド処理不可)
フォーム制約フォームバックエンドなし（送信完了UI のみ、実メール送信は将来検討）
画像制約著作権フリーまたは自社所有画像のみ使用可能

ブランド制約カラーパレット・ロゴは ITS 社規定に従う
