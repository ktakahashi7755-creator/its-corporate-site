Section 01

CSS設計詳細

1.1 デザイントークン体系（css/style.css）

全スタイルは :root で定義するカスタムプロパティ（デザイントークン）に基づく。トークンは「意味的長形式（--color-primary）」と「短縮エイリアス（--c-primary）」の二重定義を採用し、familink.html の既存コードとの後方互換性を保つ。

css/style.css — デザイントークン（抜粋）
:root {
  /* Primary Colors */
  --color-primary:      #0A84FF;
  --color-primary-dk:   #0060D8;
  --grad-primary: linear-gradient(135deg, #0A84FF 0%, #5AC8FA 100%);

  /* Motion */
  --ease-out:      cubic-bezier(0.16, 1, 0.3, 1);
  --duration-fast: 0.2s;
  --duration-base: 0.35s;

  /* Shorthand aliases for familink.html */
  --c-primary:   #0A84FF;
  --ease:        cubic-bezier(0.16, 1, 0.3, 1);
}

4.2 IntersectionObserver 設定

js/animations.js — Stagger Observer
var io = new IntersectionObserver(function(entries) {
  entries.forEach(function(entry) {
    if (!entry.isIntersecting) return;
    var items = entry.target.querySelectorAll('.js-stagger-item');
    items.forEach(function(item, i) {
      setTimeout(function() {
        item.classList.add('is-visible');
      }, i * 130);
    });
    io.unobserve(entry.target);  // 1回のみ発火
  });
}, { threshold: 0.08, rootMargin: '0px 0px -40px 0px' });

4.3 パーティクルシステム（js/main.js）

  • Canvas API でドット粒子を描画。数 = min(width×height/12000, 110)
  • 3種類: gold(12%) / blue(33%) / white(55%) で彩度を持たせる
  • 粒子間距離 ≤ 90px の場合に接続線を描画（opacity α連動）
  • window resize で canvas サイズ再計算・粒子再生成

4.4 エラーハンドリング方針

方針：各 init 関数は対象要素が存在しない場合 early return する。DOM存在チェックを必ず先頭で行い、不要なエラーを防ぐ。存在しない場合は何もしない（サイレント失敗）。
Early Return Pattern
function initScrollProgress() {
  var bar = document.getElementById('scroll-progress');
  if (!bar) return;  // 要素なければ即返す
  // ... 処理続行
}
